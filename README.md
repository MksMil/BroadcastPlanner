



# Broadcast planner
 Broadcast planner - program to planing broadcasts for sport events by producers, and tracking job by broadcast crews.
 SwiftUI + SpriteKit.
 CoreData, Firebase.
 
 developing in progress.
 evolution of UI is endless...
 
* Auth and linking with Apple, Google, e-mail. 
* Save all data in coredata and firebase
* synchronization with listeners
* broadcast contains venue, two clubs, time and date, blueprint of pitch positions, owner (user that create, owner can add/remove other users to ownerGroup),and participants
* broadcastList has filters all/"were I'am participant"/"created by myself", and single expired button
* blueprint is a customizable sprite scene with ability to add/edit/remove "pitch positions", save as template, load from templates
* all data is in live syncronization with firebase.
* cleaning local data garbage mechanism (unused photos ets.)
* cache for photos
* messenger is in progress
